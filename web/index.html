OLED verification

The integrated OLED is shown in its photographed position. Controller, pixel resolution, SDA, SCL, I²C address and shared header connections are unverified for the ZEK-03.

This viewer does not initialize the OLED or change GPIO modes. Similar-looking boards are not enough evidence to assign its internal wiring.

How the live viewer works

The page is served by Mzansi on port 80. It reads the original viewer’s event stream on port 8080 and merges changed pin values. Both viewers share the same configured sampling interval.

The API key checks the main dashboard connection; the upstream port 8080 stream itself has no authentication. Use a trusted local network. Enable GPIO Live first and wait two minutes after restart.

TX/RX are mapped to GPIO21/20 using this project’s recorded UART wiring and NMEA test. Manufacturer confirmation remains unavailable. GPIO2, 8 and 9 are C3 strapping pins; preserve startup levels. OLED sharing is unknown.
