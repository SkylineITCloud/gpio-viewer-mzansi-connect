# Release history

## 1.0.0 - 18 November 2026

- Added the Zepkvor ZEK-03 visual profile with photo-confirmed header order.
- Added a self-contained local viewer consuming GPIOViewer 1.7.1 SSE deltas.
- Added selection, digital/PWM/ADC values, mode display, stale state, reconnect,
  pause/resume, a rolling selected-pin chart and generic pin list.
- Added separate Mzansi dashboard and Android 1.3.0 menu entries.
- Retained the original GPIO Viewer on port 8080.
- Integrated a non-blocking GPIO8 network LED in Mzansi firmware 2.2.6.
- Marked ZEK-03 OLED internals and LED polarity verification limits explicitly.
